# Aplicación de Proyecto DAW
## 1. Descripción
Página web del curso DAW2: portada con las asignaturas, enlaces a los proyectos de cada una, y pagina de error

## 2. Requisitos
- Un servidor web, como Apache.

## 3. Instalación
Clonar el repositorio:
`git clone https://github.com/Juan-D07/JDPProyectoDAW`

Acceder a la carpeta del proyecto:
`cd JDPProyectoDAW`

Iniciar el servidor de desarrollo de PHP:
`php -S localhost:8000`

## 4. Uso
Una vez iniciado el servidor:

Abrir un navegador web.
`Acceder a http://localhost:8000.`
Visualiza las asignaturas
## 5. Estructura del proyecto

```bash
JDPProyectoDAW/
├── index.html
├── .htaccess
├── docs
├── error
└── webroot
```
